Insurance Claim Approval Process

An end-to-end, hands-on workshop for building agentic automation on UiPath — using a real-world insurance claim approval process as the running example. You'll progress from a conversational intake agent, to an autonomous fraud agent, to a code-first settlement agent, and finally to full orchestration with Maestro.

What you'll build

This workshop takes you from zero to a working, agentic automation solution for a real insurance claim process. Rather than treating each UiPath capability in isolation, every lesson builds toward the same use case, inside one Studio Web solution — an Insurance Claim Approval Process — so you experience how conversational agents, orchestration, autonomous agents, and coded agents fit together in a single enterprise-grade solution.

By the end of the workshop, you will have built a conversational agent that captures claim intake through UiPath Apps, an autonomous agent that detects fraudulent claims, and a coded agent that calculates settlements — and orchestrated all of them, with a human review and GenAI-written emails, in a Maestro BPMN process.

What you will learn

✓
Claim Intake — create Insurance_Claim_Solution and its conversational Insurance Claim Agent with contexts and tools, test it with a pack of sample claims, deploy it and embed it in the Claim App.
✓
Claim Approval Process — import the ready-made BPMN file and configure each task: the start event on the claim entity, the autonomous Fraud Detect Agent, the document download, supervisor review and claimant notification.
✓
Settlement Coded Agent — add a Python LangGraph agent to the same solution, test it locally with the UiPath CLI, push it to Studio Web and map it in Maestro.
✓
Decision and Deployment — generate and send the decision email with GenAI, test every path end to end and deploy the whole solution together.

Key concepts

  • Conversational Agent — an agent that interacts with users in real time to collect information, such as claim details, through a chat-style interface.
  • Maestro — UiPath's orchestration platform for coordinating humans, robots, and AI agents across long-running business processes, using either BPMN or Flow.
  • Agent Builder — the low-code experience for designing autonomous and conversational agents directly in Studio.
  • Coded Agent — an agent authored in Python or another SDK-supported language, packaged and published to Orchestrator like any other automation.
  • HITL (Human-in-the-Loop) — checkpoints where a human reviews or approves an agent's decision before the process continues.
💡 Prerequisites
Access to UiPath Studio Web on your assigned tenant, and a UiPath Automation Cloud account. No prior agent-building experience required — each lesson builds on the last.
