Module 1 · Lesson 2 of 9

Create Agent

In this lesson you create the conversational agent in Studio Web, name it, pick a model, and set the greeting your users will see.

1

Start fresh

In Studio Web click Start building and choose Agent. In the Select agent type dialog (1) select Conversational under Low-code, then (2) click Start fresh.

Chose Conversational and clicked Start fresh.
2

Rename the solution and the agent

In the Explorer right-click the solution and choose Rename. Rename the solution and the agent as shown below, replacing YourName with your own name or initials.

ItemName
SolutionInsurance_Claim_CN_Solution_YourName
AgentInsurance_Claim_CN_Agent_YourName
📝 Naming
Consistent names make it easy for your instructor to find your work on the shared tenant.
Renamed the solution to Insurance_Claim_CN_Solution_YourName.
Renamed the agent to Insurance_Claim_CN_Agent_YourName.
3

Select a model

Open the agent Definition. Under Model open the dropdown and select any available LLM (for example the one marked Suggested).

Selected an available model.
4

Add the welcome title and description

Scroll to Appearance and enter the welcome text users see when the chat opens.

FieldValue
Welcome titleClaims Assistant
Welcome descriptionI'll verify your policy, check your coverage, and guide you through submitting a claim step by step.
Entered the welcome title and description.
5

Open the starting prompts

Under Starting prompts click Edit starting prompts.

Opened the Starting prompts builder.
6

Add the display prompts

In the Starting prompts builder (1) add one pair per row using Add starting prompt. The Display prompt is the button label users see; the Actual prompt is what is sent to the model. Use the same text for both, then (2) click Save.

Display promptActual prompt
Start a new claimStart a new claim
Verify my policyVerify my policy
Check required documentsCheck required documents
How does the claim process work?How does the claim process work?
💡 Why these four
The system prompt routes the first message by these exact phrases, so keep the wording unchanged.
Added the four starting prompts and clicked Save.
