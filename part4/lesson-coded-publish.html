Publish and Run the Coded Agent

38

Deploy to Personal Workspace

PowerShell
uip codedagent deploy --my-workspace

Personal Workspace is your own user-specific Orchestrator feed. It is private to you, so it is the safe choice for this workshop and for personal testing. For shared use, deploy to a tenant or folder feed with --tenant or --folder.

Deployed the agent to my Personal Workspace.
39

Run the deployed agent

PowerShell
uip codedagent invoke agent --file input.json

Open the returned monitoring link, or inspect the job in Orchestrator. Confirm that the output contains eligible, settlement_percentage, settlement_amount and message with the expected values.

Invoked the deployed agent and confirmed the output fields.
40

Understand model and unit consumption

Publishing does not itself consume model units. Consumption occurs when the agent runs and calls the model.

  • UiPath-hosted models are generally charged per LLM call. This single-node example normally makes one LLM call per run.
  • Under Flex licensing consumption is measured in Agent Units; under Unified Pricing it is measured in Platform Units.
  • Customer-managed models can be charged once per agent run instead of per LLM call.
  • Additional LLM guardrails can create additional model calls and consumption.

The exact rate depends on the tenant plan, selected model, token size and hosting configuration. Check the execution trace and the Automation Cloud licensing page for the authoritative amount.

Use the agent in Maestro

Publishing the agent does not automatically replace an existing Maestro task. In the Maestro process (the Settlement Coded Agent lesson), select your published agent for the SettlementCodedAgent task and map the fields explicitly.

DirectionFields
Inputsinsurance_type, coverage, claim_amount
Outputseligible, settlement_percentage, settlement_amount, message
💡 Good practice
Test the process in a copy first. Add a gateway after the agent that prevents an approval email when eligible is false. For real payouts, calculate settlement_amount deterministically in code and require human review.

Troubleshooting

ProblemSolution
uip is not recognizedRestart PowerShell and run uip --version. Confirm npm global packages are on PATH.
Package import errorActivate .venv, run uv pip install uipath-langchain, then uip codedagent setup --force.
Model not foundRun uip codedagent list-models and use a model allowed by the tenant.
Shows as a Function instead of an AgentCreate a new project with uip codedagent new and confirm langgraph.json exists.
Version already existsIncrease the patch version in pyproject.toml before redeploying.
Incorrect arithmeticMove multiplication and rounding out of the prompt and into deterministic Python code.
Nothing changed in the cloudRun uip codedagent init when schemas changed, then deploy a new package version.
Access denied creating folders or the venvYou are in a system folder or an Administrator window. Redo the working-folder step.
