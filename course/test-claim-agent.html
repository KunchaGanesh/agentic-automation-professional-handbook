Test the Insurance Claim Agent

Before deploying, run the agent in the debugger and walk through a full claim.

14

Debug and chat with the agent

Click Debug in the top toolbar.

The Chat panel opens with the welcome title and the four starting prompts you created. Click Start a new claim (or type it) and press Send.

The chat panel also lists the tools and debug logs. Type in Talk with your agent… or click the suggestion Hi, what can you do?. The warning "provisioning step was skipped" in the logs is expected.

Answer the agent's questions one at a time. Use this sample claimant:

QuestionSample answer
NamePriya Singh
Policy numberPOL-2024-23489
Incident typeVehicle Damage
Claim amount166500
Incident descriptionBumper and headlight repair after collision
Supporting documentPOL-2024-23489_Fraudulent_Active.pdf

Upload the supporting PDF when asked (or reply Skip), review the claim summary, then type Submit. The agent runs the IXP tool on the file and then the SaveClaimInformation workflow, which returns the official Claim ID with status Pending Review.

📝 Feedback icons
Under each agent reply you can copy the message or give it a thumbs up / thumbs down. Feedback attaches to the execution trace and is reviewed on the agent's Feedback tab after deployment.

15

Test with more sample claims

One claim is not enough to trust an agent. Download the sample claim pack and run the scenarios below in a fresh debug chat each time (click New claim between runs). Every invoice belongs to a real record in the PolicyRecords entity, so the policy lookup and coverage check return real values.

ClaimInvoices_Sample.zip — 49 claim invoices (PDF), 25 marked Fraudulent and 24 NonFraudulent. You can also download single files from the tables below.
💡 How to read a file name
POL-2024-23513_NonFraudulent_Active.pdf = policy number, the label the Fraud Detect Agent should reach later in the process, and the policy status. The chat answers below match what is printed on each invoice; the description is the invoice's Incident Ref.
