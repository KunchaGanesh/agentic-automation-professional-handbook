Create the Insurance Claim Agent

In this lesson you create the conversational agent in Studio Web, name it, pick a model, and set the greeting your users will see.

1

Create the agent and start fresh

In Studio Web click Create New and choose Agent under Building blocks. This creates the solution that will hold every project in this course.

In the Select agent type dialog (1) select Conversational under Low-code, then (2) click Start fresh.

Chose Conversational and clicked Start fresh.
2

Rename the solution and the agent

In the Explorer right-click the solution and choose Rename. Rename the solution and the agent as shown below. You will add every other project in this course — the Claim App, the Maestro BPMN process, the Fraud Detect Agent and the Settlement Coded Agent — to this same solution.

3

Select a model

Open the agent Definition. Keep the Standard harness, open the Model dropdown and select Claude Sonnet 4 (or the model your instructor names).

Why the model choice matters

The model is the agent's brain: it reads the system prompt, decides which question to ask next, when to query PolicyRecords and InsurancePolicyData, when to call the IXP and SaveClaimInformation tools, and how to word every reply. A conversational intake agent has to follow a long, strict rulebook (one question per turn, never invent values, call the save workflow only once after Submit), so pick a model that is strong at instruction following and tool calling. Claude Sonnet 4 is a good balance of accuracy, speed and cost for this; a smaller model is cheaper but more likely to skip a rule or call a tool at the wrong time.
