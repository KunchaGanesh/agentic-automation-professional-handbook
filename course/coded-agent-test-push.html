Test and Push the Coded Agent

Use one input.json file for every test. For each test, open input.json (notepad .\input.json or notepad input.json), replace its entire contents with that test's JSON, save, close Notepad and run the agent. These runs call the configured LLM — they are not offline simulations.

Run the agent (same in both shells)
uip codedagent run agent --file input.json

💡 Test acceptance rule
Every run must end with Successful execution. Tests 1 and 2 must be eligible; tests 3, 4 and 5 must be ineligible with a zero settlement. A FutureWarning or resource-overwrite message is fine if execution succeeds. If any test fails, correct main.py, run uip codedagent init and repeat all tests.
📝 If the instructor requires both shells
Run all tests in PowerShell, close it, open Command Prompt and repeat them after cd /d "%USERPROFILE%\Settlement_Coded_Agent" and call .venv\Scripts\activate.bat. The results must match. Push only once, from the shell that holds the completed project.

⚠️ Push returns HTTP 400 Bad Request?
Look at the request URL in the error. If it contains .../Project/%your-id%/..., .env has % signs around the ID: rewrite it with the plain ID, check it with type .env or Get-Content .env and push again. Setting the variable in the shell does not fix it — correct the .env file itself. If the URL looks right, compare the ID with the one shown in Studio Web.
