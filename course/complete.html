You built the whole Insurance Claim Solution — from conversational intake to an orchestrated, agent-driven approval — in one solution.

One solution across the UiPath Platform

You built a complete, end-to-end agentic automation in a single Studio Web solution. Instead of one tool solving one task, the Insurance Claim Solution combines the core capabilities of the UiPath Platform for agentic automation — agents, robots and people working together in one orchestrated, governed process. This is what makes agentic automation useful in the enterprise: each part does what it is best at, and the platform keeps the whole process observable, auditable and under control.

🤖

Agents

You built a conversational agent that collects claims in natural language and an autonomous agent that assesses fraud risk, both in Agent Builder in Studio Web. They are grounded in your data through Context Grounding and Data Fabric, act through tools (an RPA workflow and IXP document extraction), and were measured with evaluation sets before going into the process.

🧭

Maestro

UiPath Maestro orchestrates the long-running claim process end to end on a BPMN model: an event trigger on the claim entity, agent tasks, a document download, a human task, a decision gateway, a coded agent and GenAI emails — with every run visible in the execution trail and every instance traceable.

🧑‍⚖️

Human escalation

People stay in control of high-stakes decisions. The ClaimSupervisorReview action app turns each claim into a task in Action Center, where a supervisor reviews the agent's analysis and the document and approves or rejects it. Maestro waits for that decision and routes the process accordingly — human-in-the-loop by design.

⌨️

Coded agents

For logic that must be exact and repeatable, you wrote a coded agent in Python with LangGraph and the UiPath SDK and CLI. It was tested locally, pushed into the same solution, called a governed model through the LLM Gateway, and runs in Maestro like any other agent.

✨

GenAI

GenAI Activities generate the claimant's decision email in HTML from the process data, so every message is personal, accurate and consistent — without hand-written templates for each outcome.

🛡️

Governance and trust

Every model call runs through the AI Trust Layer, and the whole solution — agents, app, process and coded agent — is deployed together to Orchestrator, where it is versioned, permissioned and monitored like the rest of your automations.

What you learned

In this training you practised the full lifecycle of an agentic automation, from design to deployment:

AreaWhat you can now do
Solution designStructure a business process as one Studio Web solution, and decide which step belongs to an agent, a robot, a person or a coded agent.
Conversational agentsChoose a model and its settings, write a system prompt with clear rules, ground the agent in Data Fabric and indexes, and give it tools (RPA workflow, IXP).
Testing agentsTest an agent with realistic data, including edge cases such as mismatched documents, inactive policies and cancellations, and debug it from its trace.
Autonomous agentsDefine typed input and output arguments, design prompts that return structured results, and measure quality with evaluation sets and evaluators.
Maestro orchestrationImport a BPMN model, trigger it from a Data Fabric event, map variables between tasks, branch with gateways and debug a long-running process.
Human in the loopAdd an action app as a human task, pass it the right data and route the process on the reviewer's decision.
Coded agentsSet up the UiPath CLI, scaffold a LangGraph agent, combine an LLM with deterministic Python rules, test it locally and push it into the solution.
GenAI and integrationsGenerate HTML emails with GenAI Activities and send them through an Integration Service connector.
Deployment and governanceDeploy the complete solution together, check it in Orchestrator and trigger it live, with every model call governed by the AI Trust Layer.
