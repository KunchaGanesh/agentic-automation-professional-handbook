Settlement Coded Agent Task

Wire the solution-managed Settlement_Coded_Agent into the SettlementCodedAgent service task that runs after the Reviewer Gateway approves a claim.

68

Select your coded agent

Open Insurance_Claim_MAESTRO and select the SettlementCodedAgent task. Set Action to Start and wait for agent and choose Agent = Settlement_Coded_Agent (click Refresh if it is not listed yet).

Selected the Settlement_Coded_Agent project from this solution.
69

Map the inputs

For each input click @ → Insert variable and pick the value from the earlier tasks, for example Fraud Detection Agent → out_ClaimDetails → incident_type.

Agent inputMaestro value
insurance_typevars.outClaimDetails?.incident_type
coveragevars.response?.CoverageTypeInput
claim_amountvars.outClaimDetails?.claim_amount

fraud_verdictvars.outFraudAnalysis?.fraud_verdict
📝 Older inputs
If you still see a coverage_limit input, Studio Web has an older version of the agent. Reload Settlement_Coded_Agent after the push and click Refresh on the task.

Map the outputs

Map the agent outputs to the process variables eligible, settlementPercentage, settlementAmount and settlementMessage. Use Insert variable to select the actual output chips rather than typing names.
